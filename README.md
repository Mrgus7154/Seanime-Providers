# Seanime-Providers

Online streaming providers for [Seanime](https://seanime.app).

## Available providers

| Provider | Type | Install URL |
|---|---|---|
| Anikoto | Online streaming | https://raw.githubusercontent.com/Mrgus7154/Seanime-Providers/main/src/Anikoto/anikoto.json |

## How to install

1. Copy the Install URL of the provider you want
2. Open Seanime → Extensions → Add extension
3. Paste the URL and click Install
